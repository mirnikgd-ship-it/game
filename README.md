# 📚 Документация по игре "Zombie Waves"
🎮 Обзор игры
Zombie Waves — это динамичный 2D шутер с видом сверху, где игроку предстоит выживать против бесконечных волн зомби на фермерском поле. Игра сочетает в себе элементы survival-шутера, tower defense и RPG с системой прокачки персонажа.

🧟 Система врагов
Типы зомби по уровням (Tier)
Tier	Волны	Цвет	Особенности
0	1-2	Светло-зеленый	Базовый зомби, медленный
1	3-4	Темно-зеленый	Быстрее, со шрамами

3	7-8	Почти черный	Оранжевые глаза, очень быстрый
4	9+	Темно-красный	Максимально опасный
Характеристики зомби
Скорость: 120 + (волна × 0.15) пикселей/сек

Здоровье: 50 + (волна × 0.5) HP

Радиус: 25 + (tier × 2) пикселей

Количество: 5 + (волна × 3) зомби

🔚 Заключение
Zombie Waves — это полноценная игра с потенциалом для развития в коммерческий проект. Текущая версия уже содержит все основные механики survival-шутера: бесконечные волны врагов, систему прогрессии, улучшения персонажа и визуальные эффекты. При дальнейшей разработке игра может стать конкурентоспособным продуктом на рынке инди-игр.
